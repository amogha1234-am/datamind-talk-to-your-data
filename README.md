# DataMind — Talk to Your Data

## About the Project
DataMind is our hackathon project focused on making data easier to explore through natural-language questions.

## Problem Statement
Accessing useful information from databases can require knowledge of SQL and data analysis. Our goal was to make this process easier for users.

## Proposed Solution
An AI-powered application that helps users ask questions about data and understand the results.
